# 生活小习惯摸底

一份看起来很短的生活问卷。事情在后面。

## 这不是 zip

这是 GitHub 上的**源代码**仓库。手机要玩，请打开发布后的网页链接，不要下载 zip。

- 电脑、手机浏览器直接打开网页就能玩
- 震动在安卓上更稳，iPhone 很多时候震不了
- 声音要先点一次「开始填」

## 怎么让别人看到仓库

仓库默认是私有的。要公开：

1. 打开这个仓库
2. Settings → General → Danger Zone
3. Change repository visibility → Public

## 本地跑代码（可选）

```bash
npm install
npm run dev
```
